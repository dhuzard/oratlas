# Feature and page inventory

Baseline and evidence notation: [01](01-product-diagnosis.md). All 37 tracked `page.tsx` routes, including the homepage and `/coverage`, are represented below. `rg --files` alone omits the tracked coverage directory because of ignore rules; inventory was cross-checked with `git ls-files` and runtime. API operations are grouped by capability below; the contract checker counted 140 route operations, including two OAuth operations excluded from the JSON contract.

**Maturity:** B = locally browser-observed implementation; S = source implementation inspected, not fully exercised; P = partial/prototype; F = future/not implemented. B never implies production readiness. **Complexity:** L/M/H is a heuristic UX assessment, not a usability-test score. **Mission:** core = comparison/traceability; enabling = supports it; peripheral = specialist. **Workflow:** 1 = primary proposed flow; 2 = secondary. **Actions:** ADVANCED means MOVE TO ADVANCED; HIDE removes promotion, not access; MERGE combines presentation, not stored identities. V applies to implementation/purpose; all disposition judgments are R, based on I; their user benefit remains H.

## Concrete removals and maturity cautions

**REMOVE** the duplicate topic-entry control, “verified publication” blanket CTA, and novice requirement to enter a stable node ID. **HIDE** unimplemented private/import promises. **DEPRECATE** standalone navigation promotion of Discuss and speculative adapter roadmaps, while keeping deep links/help.

Do not remove any scientific record/table/API on this audit's evidence. No telemetry establishes unused functionality. An implemented endpoint plus tests is still not proof of operational deployment, external service acceptance or scientific correctness. The source-credit test failure and the remaining validation limits are recorded in [evidence](evidence/README.md).

Follow-up browser evidence upgrades the legacy review, claim passport, sign-in and editorial read surfaces from S to B for those bounded paths; their mutations remain S. It also confirms the P0 scientific-wording problem: claim passports display computed “independent families”; `/synthesis` source labels rule-derived candidates “Genuine contradiction.” **REMOVE** those unsupported human-facing assertions, while retaining overlap facts and compatible machine fields until an explicit migration is reviewed. Explore's interactive SVG also has one observed serious axe violation; simplify its semantics as well as its presentation.
