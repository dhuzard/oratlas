# Owner decision register: identity and private-workspace proposals

**Status: Ratification recorded 2026-10-20.** Owner ratified ADR §14.1–14.6 (refinements) and §15
(PoC model). Identity-decision items I1, I2, I3 (baseline framework) and S1 (session design
commission) approved with ORCID as primary identifier per checklist decision source. This register
records the approved choices. No persistence, session or workspace policy is yet implemented.

## What is already recorded

- [ADR §12](./private-workspace-security-architecture.md#12-decisions-requiring-owner-ratification) is the authoritative historical D1–D11 record. D1–D10 are adopted; **D11 remains provisional**, requiring counsel and DPIA confirmation. Do not renumber or reinterpret those decisions in this register.
- Per the owner's statements, ORAtlas is an owner-operated PoC; personal experiments and independent-researcher private-workspace testing are intended. The owner reports no private data yet; this is not an independent audit.
- The synthetic-only initial content restriction, draft hosted notice and readiness conditions in §15 were accepted on 2026-10-20. Implementation and readiness evidence remain required before external access. Platform ownership does not confer rights in other people's data.

Manual ORCID entry must validate checksum and query the ORCID API. A matching public record is
**API-recognized, ownership unverified**; only authenticated OAuth proves identifier control.
API errors/unavailability substantiate neither recognition nor nonexistence. ORCID is primary for
researcher identification, not mandatory for local GitHub login or a source of workspace authority.
These are approved requirements, not claims of implemented API checking.

## Dependency boundary

The [G1 harness specification](./private-workspace-g1-harness.md) can be refined independently of these identity choices. Relevant I1–I4 decisions and reviewed S1/A14.2 semantics precede policy-dependent persistence/session implementation. G1 must pass before private tables; authorization/invitations, G3 protection and the applicable later gates remain separate. D11 is not resolved by G1, a merged PR, or engineering tests.
